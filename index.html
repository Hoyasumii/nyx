Como funciona

  1. 01

    Solte o arquivo

    Arraste um PDF ou PPTX para a página, ou escolha pelo seletor. A leitura acontece ali mesmo, no navegador.

  2. 02

    Revise os slides

    Navegue pela tira de miniaturas ou abra a grade para pular direto para qualquer slide.

  3. 03

    Apresente

    Tela cheia com um toque. O cursor vira uma pequena lente que se adapta ao fundo, clara ou escura, para você nunca se perder no slide.

Perguntas

Meu arquivo é enviado para algum servidor?

Não. O Nyx é um site estático: o PDF ou PPTX é lido inteiramente pelo seu navegador e nenhum byte sai do seu computador. Você pode até desconectar a internet depois que a página carregar.

Quais formatos são aceitos?

PDF e PowerPoint (.pptx). Arquivos .ppt antigos, Keynote e Google Slides podem ser exportados como PDF ou PPTX antes.

O PPTX fica idêntico ao PowerPoint?

Textos, imagens, formas, tabelas e fundos são reproduzidos. Animações, vídeos e gráficos nativos ficam de fora. Se a fidelidade for essencial, exporte como PDF: ele sai pixel a pixel.

Funciona no celular?

Sim. Deslize para os lados para trocar de slide. O holofote aparece só com mouse, já que no toque não existe cursor.
